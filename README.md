# Community Mod

Community Mod is a private Minecraft mod library for sharing and downloading mods.

## Features

- Browse the featured Sus Chunk Finder mod.
- Submit a mod with its name, version, description, and download link or file.
- Keep the simple dark community library layout in `public/`.

## Website

The website files are in the `public/` folder. GitHub Pages is currently unavailable because this is a private personal repository on the current plan.
